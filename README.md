## Sobre o Projeto

O DeliveryCalc é um programa desenvolvido em Java para calcular o valor de pedidos de entrega e retirada.

O sistema considera o valor dos produtos, os descontos aplicados e a cobrança de frete, de acordo com o tipo de pedido escolhido.

O projeto foi desenvolvido para colocar em prática conceitos de Programação Orientada a Objetos.

## Funcionalidades

* Cálculo do valor total de pedidos
* Aplicação de descontos
* Cálculo de frete para entregas
* Pedidos com retirada no local
* Exibição do valor final do pedido

## Regras para o calculo 
| Tipo de pedido | Desconto | Frete    |
| -------------- | -------- | -------- |
| Delivery       | 10%      | R$ 10,00 |
| Retirada       | 15%      | Gratuito |

## Estrutura do Projeto

O código-fonte está organizado na pasta `src/sistemadelivery`.

Entre as classes do projeto estão:

* `Pedido.java`
* `Delivery.java`
* `PedidoRetirada.java`
* `CalculadoraDePreco.java`
* `PoliticaDeDesconto.java`
* `ServicoDeEntrega.java`
* `SistemaDelivery.java`

## Como Executar

1. Instale o Java e o Apache NetBeans.
2. Baixe ou clone este repositório.
3. Abra o projeto no NetBeans.
4. Execute a classe principal `SistemaDelivery.java`.
